Tutorial – Criação do Índice de Livros de Música

Objetivo: Criar o índice completo de um livro de músicas, gerar os PDFs individuais, atualizar a biblioteca e criar o lote em formato JSON.

Etapa 1 – Gerar a lista das músicas

Ferramenta: ChatGPT

Solicite ao ChatGPT a lista das músicas do livro, contendo:

  • Código
  • Nome da música
  • Compositor

Exemplo:

24207 - Simple Simon - Leila Fletcher 24208 - The Parade - Leila Fletcher 24209 - The Crocodile - Leila Fletcher

Etapa 2 – Revisar o índice

Ferramenta: Bloco de Notas

Revise a lista gerada pelo ChatGPT. Verifique:

  • Numeração correta.
  • Ortografia dos títulos.
  • Nome dos compositores.
  • Padronização do formato.

Formato final:

24207 - Simple Simon - Leila Fletcher 24208 - The Parade - Leila Fletcher 24209 - The Crocodile - Leila Fletcher

Etapa 3 – Gerar os PDFs

Ferramenta: Microsoft Edge, Bloco de Notas

Utilize o Microsoft Edge para:

  • Renomear cada música utilizando o código correspondente.
  • Imprimir cada música em PDF.

Utilize o Bloco de Notas para:

  • Conferir os nomes das músicas.
  • Copiar o código.

Exemplo:

24207.pdf 24208.pdf 24209.pdf

Etapa 4 – Atualizar a biblioteca

Ferramenta: Planilhas Google

Adicionar uma nova linha para cada música contendo:

  • Código
  • Nome da música
  • Compositor

Exemplo:

Código | Música | Compositor 24207 | Simple Simon | Leila Fletcher 24208 | The Parade | Leila Fletcher 24209 | The Crocodile | Leila Fletcher

Etapa 5 – Enviar os PDFs

Salvar todos os arquivos PDF na pasta do GitHub:

https://github.com/musicanplay3-sudo/m-pav/tree/main/partituras

Etapa 6 – Criar o lote JSON

Acesse o Painel Admin:

  • Cadastrar Novo Lote
  • Tipo de Lote: Repertório de Músicas
  • Nome do Lote (ID Único): Escrever apenas o código do livro seguido de "_pdf".
    Exemplo para: 7363 - PDF - PIANO - James Bastien - Piano Basics Performance - Level 4 → 7363_pdf
  • Itens do Lote (Um por linha): Copiar ou digitar uma música por linha no formato Código - Nome da Música - Compositor.

Exemplo:

24207 - Simple Simon - Leila Fletcher 24208 - The Parade - Leila Fletcher 24209 - The Crocodile - Leila Fletcher

Finalização

Clique em: Salvar Lote no GitHub. Após salvar, o arquivo JSON será criado automaticamente e ficará disponível para utilização na biblioteca.

Fluxo resumido

  • ChatGPT → Gerar lista das músicas.
  • Bloco de Notas → Revisar e corrigir o índice.
  • Microsoft Edge → Renomear e imprimir cada música em PDF.
  • Planilhas Google → Atualizar a biblioteca (Código, Música e Compositor).
  • GitHub → Enviar todos os arquivos PDF para a pasta partituras.
  • Painel Admin → Criar o lote JSON e salvar no GitHub.
