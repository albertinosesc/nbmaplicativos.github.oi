📖 Tutorial

Este editor suporta notação ABC — um formato de texto simples para escrever partituras. Basta envolver o código ABC com [ABC] e [/ABC].

1. Estrutura básica

[ABC]
X:1
T: Nome da música
M:4/4
L:1/8
K:C
C DEF | GAB c |]
[/ABC]

O bloco [ABC]...[/ABC] pode conter várias linhas de diretrizes (X:, T:, M:, etc.) seguidas das notas musicais.

2. Diretrizes avançadas (%%)

DiretrizO que fazExemplo
%%transpose=NTranspõe a partitura em N semitons%%transpose=2
%%staffwidth=NLargura da pauta em pixels%%staffwidth900

3. Estilo isolado por bloco

Envolva o bloco com <div> e <style> para escopar o CSS. Cada bloco pode ter seu próprio estilo:

<div class="meu-estilo">
<style>
.abcjs-chord { fill: red !important; font-size: 24px !important; }
</style>

[ABC]
X:1
T: Exemplo
M:4/4
L:1/8
K:C
"C"C DEF | "G"GAB c |]
[/ABC]
</div>

4. Entendendo a regra CSS dos acordes

A regra abaixo estiliza os acordes (D, Bm, G, A...) da partitura:

.abcjs-container svg .abcjs-chord {
    font-size: 24px !important;
    font-weight: bold !important;
    fill: red !important;
    transform: translateX(5px) translateY(24px);
}
  • .abcjs-container svg .abcjs-chord — seleciona todos os acordes dentro da partitura ABC. A classe .abcjs-chord é aplicada automaticamente pelo ABCJS em cada acorde.
  • font-size: 24px — tamanho da fonte dos acordes.
  • font-weight: bold — deixa o texto em negrito.
  • fill: red — como o ABCJS gera SVG, a cor do texto é definida por fill (não por color).
  • transform: translateX(5px) translateY(24px) — desloca o acorde 5px para a direita e 24px para baixo.
  • !important — força a regra a sobrescrever o CSS interno do ABCJS.

5. Classes CSS úteis do ABCJS

  • .abcjs-chord — acordes (C, G, Am...)
  • .abcjs-note — notas musicais
  • .abcjs-staff — pauta (pentagrama)
  • .abcjs-bar — barras de compasso

6. Informações sobre a <div>

A <div> é usada para agrupar elementos e controlar o tamanho dos diagramas.

6.1 Redimensionar

Envolva um diagrama numa <div> com largura fixa:

<div style="width: 500px;">
  [cole o diagrama aqui]
</div>

6.2 Agrupar acordes com propriedades comuns (DRY)

O CSS vai uma vez só no <style> do grupo. Cada acorde adicional custa apenas ~90 caracteres:

<div class="cg" style="--c:#e94560; --s:20px; --w:140px; --mb:-18px;">
  <style>
  .cg { display: block; text-align: var(--ta, center); margin: 12px 0; }
  .cg .c { display: inline-block; vertical-align: top; margin: 8px 14px; text-align: center; width: var(--w, 140px); max-width: 100%; box-sizing: border-box; }
  .cg .c .cn { font: bold var(--s, 20px) sans-serif; color: var(--c, #e94560); margin-bottom: var(--mb, -18px); }
  .cg .c svg { display: block; margin: 0 auto; width: 100%; height: auto; }
  </style>
  <div class="c"><div class="cn">C</div><svg>...</svg></div>
  <div class="c"><div class="cn">G</div><svg>...</svg></div>
</div>

Variáveis disponíveis:

VariávelO que controla
--cCor da cifra
--sTamanho da fonte da cifra
--wLargura de cada acorde
--mbMargem inferior (negativa aproxima os acordes)
--taAlinhamento (center, left, right)

6.3 Fluxo dos acordes

Os acordes ficam lado a lado automaticamente e quebram linha só quando não couberem no espaço disponível. Isso funciona dentro de qualquer <div> — se a div tiver 500px, os acordes quebram quando passarem de 500px.
