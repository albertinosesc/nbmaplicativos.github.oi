📖 Como funciona?

📊 Estrutura da Planilha

Cada aba é uma progressão diferente. Colunas:
A = Código | B = Harmonia | C = Músicas

🔍 Como buscar

Use os filtros de Código, Progressão ou Música. Os resultados aparecem automaticamente.

📝 Células Mescladas

Quando um código/harmonia tem várias músicas, as células A e B ficam mescladas. O sistema entende isso automaticamente.

🛠️ Como configurar sua planilha

  1. Crie uma planilha no Google Sheets
  2. Crie abas com nomes de progressões (ex: I_V, I_IV_V)
  3. Em cada aba: Coluna A = Código, B = Harmonia, C = Músicas
  4. Mescle as células A e B quando o código/harmonia se repetir
  5. Vá em Extensões > Apps Script e cole o script
  6. Implante como aplicativo web e copie a URL
  7. Cole a URL no campo de configuração abaixo
